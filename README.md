# Segsmaker — Parallel Fork

> **Optimized for Speed. Efficiency is the Standard.**

This is a custom fork of Segsmaker featuring a completely revamped, #@param-based UI and a true parallel download engine for maximum bandwidth utilization.

### Features
- **Parallel Batch Downloading**: 10 simultaneous workers, each maxed at 16 connections.
- **Revamped Colab UI**: Clean, 11-cell structure using interactive `#@param` widgets.
- **FLUX Support**: Native FLUX 1-schnell & 1-dev integration.
- **Temporary Models**: Download directly to `/tmp` to avoid hitting Colab disk limits.

### Supported WebUIs
- A1111
- Forge
- ReForge
- Forge Classic
- Forge Neo
- ComfyUI
- SwarmUI
